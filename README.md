## 🧱 Field summary

- `domain`, Fully qualified domain name.
- `status`, Current acquisition state for the domain in the public extract.
- `purchase_price`, Visible purchase price when available.
- `renewal_price`, Visible renewal price when available.
- `attractiveness`, Public composite naming band used as a decision-support signal.
- `demand`, Public buyer-pressure band when available.
- `length`, Character count without the TLD.
- `registrar`, Registrar name when known.
- `created_at`, Creation timestamp when known.
- `expires_at`, Expiry timestamp when known.

See [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) for full definitions and types.

## ⚠️ Methodology and caveats

This selection includes 12,634 one-word .makeup domain names across a wide range of themes, from direct beauty terms to abstract, brandable phrases such as turninto.makeup, solarpower.makeup, and appreciation.makeup. The median ask across the set is near $211, positioning most of these domains as accessible acquisitions rather than premium plays. Because .makeup is a niche, industry-specific extension, availability tends to be higher and pricing more moderate than equivalent .com options, though buyers should still confirm renewal costs and check for trademark conflicts before committing to a name.
